## Objetivo
O objetivo desse dashboard é fornecer uma visão geral das vendas de assinaturas do Xbox Game Pass, permitindo monitorar os valores totais arrecadados.

## Observação
- Arquivo em Excel com banco de dados fictício.

### Descrição
Um painel de controle interativo que exibe os resultados financeiros das vendas de assinaturas do Xbox Game Pass em um período específico (01/01/2024 a 31/12/2024). O dashboard segmenta as receitas por tipo de serviço (EA Play, Minecraft Season Pass e Xbox Game Pass) e apresenta o desempenho do Xbox Game Pass com base na adesão (sim ou não).

### Funcionalidades
- Exibir o total de assinaturas e receitas geradas pelo EA Play Season Pass e Minecraft Season Pass;
- Exibir o faturamento total do Xbox Game Pass, comparando assinantes que aderiram ao EA Play Season Pass com aqueles que não aderiram;
- Permitir seleção do tipo de assinatura (Annual, Monthly, Quarterly) para filtrar os dados exibidos;
- Apresentar informações atualizadas com data e hora da última atualização;
- Visualizar barras de desempenho para análise comparativa das receitas entre os serviços e opções de adesão.
